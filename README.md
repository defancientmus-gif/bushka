# БУ.шка

Мобильная PWA-витрина и мини-склад для продавцов б/у техники. Идея продукта: продавец один раз собирает аккуратную карточку из фото, текста, Telegram-поста, Avito-ссылки или скрина, а потом использует ее в своей витрине, Telegram и Avito.

Это не попытка заменить Avito. БУ.шка должна стать удобным слоем порядка поверх Avito, Telegram, локальных барахолок и личных продаж.

## Что есть сейчас

- `apps/pwa` - основной новый фронтенд: React, TypeScript, Vite, mobile-first PWA.
- `apps/prototype` - сохраненный HTML-прототип из первых итераций.
- `docs` - продуктовая память: рынок, MVP, доверие, импорт/экспорт, очередь и бронь.

## Запуск новой PWA

```bash
cd apps/pwa
npm install
npm run dev
```

Vite поднимется на `http://localhost:8766/`. Для проверки с телефона открой локальный IP компьютера в той же Wi-Fi сети, например:

```text
http://192.168.x.x:8766/
```

## Деплой как полноценная PWA

Проект подготовлен под GitHub Pages. После подключения GitHub-репозитория и push в `main` workflow `.github/workflows/pages.yml` соберет `apps/pwa` и опубликует `apps/pwa/dist`.

Подробно: [docs/08-deployment.md](docs/08-deployment.md).

## Запуск старого HTML-прототипа

```bash
cd apps/prototype
python3 server.py
```

Старый прототип обычно доступен на `http://localhost:8765/`.

## Продуктовая формула

```text
Импорт -> красивая карточка -> склад продавца -> личная витрина -> доверие -> лоты -> локальное комьюнити
```

## Ближайшая цель

Собрать MVP, который продавец б/у техники может открыть с телефона и за 30-60 секунд:

1. создать карточку товара;
2. добавить фото;
3. поставить статус;
4. сохранить в склад;
5. скопировать готовый текст для Telegram или Avito;
6. дать покупателю ссылку на свою витрину.
