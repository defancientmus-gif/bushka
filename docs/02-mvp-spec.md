# MVP Spec

## Цель MVP

Дать продавцу б/у техники инструмент, который экономит время каждый день: быстро создать карточку, сохранить товар в склад, показать покупателю, опубликовать в Telegram и подготовить для Avito.

## Основные экраны

1. Создание товара.
2. Склад/лента продавца.
3. Личный кабинет.
4. Карточка товара.
5. Репост/экспорт.

## Товар

Минимальные поля:

- название;
- цена;
- категория;
- состояние;
- грейд;
- статус;
- город;
- контакт;
- описание;
- фото/видео;
- исходная ссылка;
- продавец.

Дополнительные поля для техники:

- батарея;
- память/накопитель;
- комплект;
- дефекты;
- гарантия;
- серийник/IMEI в приватном поле позже.

## Статусы

- `В наличии`
- `Бронь`
- `Продано`
- `Обмен`
- `Лот`

## Режим сделки

- `Свободная продажа` - продавец сам выбирает покупателя.
- `Живая очередь` - первый подтвержденный получает бронь.
- `Лучшее предложение` - продавец выбирает по цене и условиям.

По умолчанию: `Свободная продажа`.

## MVP-импорт

1. Текст объявления.
2. Telegram-ссылка.
3. Avito-ссылка с fallback по slug, если Avito блокирует запрос.
4. Скрин объявления позже: OCR/AI как отдельный модуль.

## MVP-экспорт

1. Скопировать текст для Telegram.
2. Скопировать текст для Avito.
3. Скопировать короткую карточку для личного сообщения.
4. Позже: Telegram Bot API для автопубликации.
5. Позже: Avito XML/feed/API для проф. продавцов.

## Критерий готовности MVP

Продавец с телефона может создать товар и получить готовую карточку быстрее, чем он оформит пост вручную в Telegram.
