# UX Principles

## Mobile first

Продавец чаще всего работает с телефона: сфотографировал товар, вставил текст, скинул ссылку, отправил пост. Поэтому первый интерфейс - телефон. Десктоп поддерживаем адаптивной версткой, но не проектируем отдельное desktop-приложение.

## Без лишних объяснений

Пользователь понимает, куда пришел. Интерфейс не должен обучать очевидному. Лучше короткие названия полей, ясные статусы и быстрые действия.

## Минимум кнопок

Основные действия:

- импорт;
- фото;
- сохранить;
- скопировать для репоста;
- поставить статус;
- контакт.

## Карточка важнее текста вокруг

На первом экране должен быть товар и действие продавца, а не маркетинговое описание сервиса.

## Статусы видны сразу

Покупатель должен понимать: товар в наличии, в броне, продан, обмен или лот. Продавец должен менять статус в один тап.

## Не обещать лишнего

Фраза "запрос отправлен" лучше, чем "вы первый". Бронь появляется только после явного подтверждения продавца.

## Доверие тихое, но постоянное

Рейтинг, сделки, срок на площадке и подтвержденные действия должны быть рядом, но без ярмарки звезд.
