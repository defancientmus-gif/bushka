# Import And Export

## Главная продуктовая идея

> Создал один раз - использовал везде.

Продавец не должен переписывать одно и то же объявление для Telegram, Avito, личных сообщений и собственной витрины.

## Telegram

Реалистичный сценарий:

1. Продавец добавляет бота в свой канал или чат.
2. Создает карточку в БУ.шке.
3. Нажимает "Опубликовать в Telegram".
4. Бот отправляет фотоальбом, цену, описание, контакт и ссылку на карточку.

Это официальный и устойчивый путь через Telegram Bot API.

## Avito

Реалистичные уровни:

| Уровень | Оценка | Комментарий |
| --- | --- | --- |
| Подготовить объявление | Сразу | Генерируем название, описание, цену, фото и даем скопировать |
| Ссылка на Avito в карточке | Сразу | Продавец связывает витрину БУ.шки и Avito |
| Автозагрузка XML/feed | Позже | Для проф. продавцов и категорий, где доступна автозагрузка |
| Полная API-интеграция | Позже | Нужны доступы, OAuth и соответствие правилам Avito |
| Автоматизация браузера | Не ядро | Хрупко: капчи, блокировки, изменения интерфейса |

## Почему Avito плохо парсится

Avito часто блокирует прямые серверные запросы антибот-защитой. Поэтому надежная стратегия:

- не обещать полный парсинг всем;
- делать fallback из ссылки;
- принимать "ссылка + текст";
- позже добавить импорт со скрина через OCR/AI;
- хранить исходную ссылку как контакт/источник.

## Скрин объявления

Сценарий:

1. Пользователь загружает скрин Avito или Telegram.
2. OCR/AI вытаскивает название, цену, описание, город.
3. Фото товара пользователь загружает отдельно, чтобы не терять качество.

Это хороший обход ограничений парсинга без сомнительных антибот-обходов.
