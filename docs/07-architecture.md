# Architecture

## Выбранный путь

Один web-продукт:

- mobile-first PWA как основная поверхность;
- адаптивная десктоп-версия в том же коде;
- без отдельного native desktop на старте;
- без Electron на старте.

## Почему так

Продавец работает с телефона: фото, Telegram, Avito-ссылка, быстрый контакт. PWA быстрее довести до проверки гипотезы, чем native-приложение.

## Стек

Frontend:

- React;
- TypeScript;
- Vite;
- CSS без тяжелой UI-библиотеки на первом этапе.

Backend позже:

- Supabase Auth;
- Supabase Postgres;
- Supabase Storage;
- Edge Functions для импорта и AI/OCR.

Интеграции:

- Telegram Bot API;
- Avito export сначала через подготовку текста, потом XML/feed/API при доступе.

## Доменная модель

Основные сущности:

- `Profile` - продавец.
- `Item` - товар или лот.
- `MediaAsset` - фото/видео.
- `Lead` - запрос покупателя.
- `Reservation` - подтвержденная бронь.
- `Review` - отзыв по сделке.

## Важная граница

Запрос покупателя не равен брони. Бронь - отдельное событие, которое делает продавец.
