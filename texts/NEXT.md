# NEXT — текущее

## Где мы (2026-06-13)
v0.2.0 на проде. Получен TECH_PROMPT — система «Женя + Инженер» закреплена в `CLAUDE.md` и `texts/`. Решения Жени по развилке: **начинаем с покупательской грани**, фундамент **пока локально на моках** (проектируем под Supabase).

## Образ покупательской ленты (слово Жени)
«Скупить рынок лёжа на диване — точно купим, а не будем парить мозги продавцу.» → Лента изобильная, решительная, ноль трения: цена крупно, видно как забрать (доставка/самовывоз/встреча), действие — **«Беру»** (один тап → продавец), не «задам вопросик».

## Сделано этой сессией
- **Покупательская грань**: новый главный экран **Рынок** (`MarketView`) — щедрая лента моков (12 лотов), фильтр по категориям, поиск, карточка с тегами доставки, рейтингом продавца ★, кнопкой «Беру» (открывает контакт) и сердечком в избранное.
- **Навигация**: 3 кнопки → Рынок / Создать / Профиль.
- **Два кабинета без 4-й кнопки**: профиль раздвоен сегментом **Покупаю / Продаю**. Покупаю — избранное + кольца (избранное/рейтинг/задания). Продаю — кольца продавца + редактирование профиля + «Мои товары» (управление статусом/репост/удаление).
- **Избранное**: лайк лота, хранится локально (`favorites:v1`).
- **Долг по дизайну (частично погашен по закону):** убран греющий блюр у фоновых линий (теперь только transform/opacity — телефон холодный), линии дрейфуют (метафора «парят/дрейфуют»), пауза под открытым шитом; срезаны декор-полоска `import-hero::before` и бегущий блик `sheen` с кнопки.

## Репост в Telegram — починен (важно)
Раньше «Репост» умел только копировать текст — фото никуда не уходили (картинки к строке не прикладывались; в прототипе их тоже не было). Сделано правильно:
- `lib/share.ts`: фото (base64 в localStorage) → настоящие `File` → **Web Share API** (`navigator.share({ files, text })`).
- На телефоне «Поделиться (фото + текст)» открывает нативный лист → выбираешь Telegram → альбом и подпись уходят вместе.
- На десктопе (нет share с файлами) — копировать текст + «Скачать фото» + подсказка открыть на телефоне.
- Проверено: dataURL→File работает; на iPhone Safari `navigator.share`/`canShare` есть → фото прикрепятся.

## Решения и почему
- Покупатель входит без выбора роли и без регистрации — для пугливой аудитории «просто посмотреть» = дверь без замка.
- «Беру» сразу открывает контакт продавца — решительность вместо переписки-торга.
- Профиль раздвоен сегментом, а не 4-й кнопкой — святое правило «3 кнопки, минимум шума» сохранено.
- Рейтинг/задания пока витрина (моки): честный рейтинг между людьми невозможен локально — это ждёт бэкенда (не подделываем — против ДНК).

## Импорт фото (важно про ограничение)
Текст-разбор работает. Фото из *ссылки* Avito/TG клиент достать не может (CORS/антибот) — в прототипе это делал `server.py`. Сейчас без бэкенда сделано максимум: **вставка скрина/фото из буфера** (кнопка «Вставить» и onPaste прямо в поле импорта) + подтягивание **прямых ссылок на картинки** (best-effort). Настоящий «ссылка → фото товара» — первый кандидат на Edge Function, когда поднимем Supabase (фетч og:image / страницы на сервере).

## Репост наружу — фокус продукта (решение Жени)
Развернули направление: не тянуть с площадок (против антибота), а **раздавать от нас** — «создал раз → отправил везде». Сделано:
- **Telegram**: «Поделиться» уже шлёт фото+текст в любой твой канал/чат (ты админ → выбираешь его в системном шите). **Бот не нужен** — он только для авто-постинга пачками (перекупам), поэтому пока не делаем.
- **Avito**: выгрузка **по полям** — отдельные кнопки копирования Заголовок / Цена (только цифры) / Описание (с характеристиками) под форму Avito + «Скачать фото для Avito». Надёжно, без аккаунтов и сервера.
- Серверный импорт по ссылке отложен (Avito антибот; Telegram og:image — позже, с Edge Function, если понадобится).

## Go-to-market / плацдарм (снимает риск «холодного старта»)
У Жени есть **свой сервис по ремонту телефонов**, он сам перепродаёт, лично знает радиорынок, много клиентов, может попросить **магазины запчастей** распространять. Это закрывает главный риск маркета (первые 100 продавцов). Следствия для продукта:
- Сервис Жени = **первая живая витрина** (он сам ежедневный пользователь — закуп запчастей/маржа + перепродажа восстановленных = dogfooding).
- Клиенты сервиса — первые покупатели; магазины запчастей — реферальная петля; радиорынок — комьюнити доверия лицом к лицу.
- → **Ключевой разблокиратор: публичная витрина по ссылке + QR** (показать клиенту, повесить у партнёров). А это требует двора (Supabase). Сильный аргумент строить двор сейчас и первым сделать витрину сервиса Жени.
