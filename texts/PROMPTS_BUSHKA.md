# Бушка — умная СРМ для перекупов (промпты + идеи)

> Для простых ребят, которые гоняют б/у телефоны. Не бухгалтерия, не Эксель, не «заполни 12 полей».
> **Один принцип: скорость. Время — наше всё.** Сделка должна заноситься быстрее, чем ты её обмываешь.

---

## Вайб (чтобы любой промпт держал стиль)

- **2 тапа или голос** — не форма. Видел товар → щёлкнул фото → лот готов.
- **Живой язык**: «купил», «продал», «в кармане», «висяк», «навар». Никакого «контрагент» и «номенклатура».
- **Цифра, которая греет**: всегда на виду — *сколько наварил сегодня* и *сколько денег в товаре лежит*.
- **Тёмная тема, крупные карточки, свайпы.** Палец, а не курсор. На ходу, одной рукой.
- **ИИ — это «второй ты»**: смотрит на фото/слышит голос и сам всё раскидывает. Ты только подтверждаешь.

---

## Интересные фишки (меню «вау»)

1. 🔥 **ИИ-оценщик по фото** — снял телефон → ИИ говорит модель, память, цвет, примерное состояние и среднюю цену по рынку. Ты только вбиваешь, за сколько берёшь.
2. 🎤 **Голосовой ввод сделки** — бормочешь «взял айфон 12, 64, синий, за 18, продам 25» → само разносится в лот с маржой.
3. 🚦 **Светофор лота** — зелёный «бери, навар жирный», жёлтый «так себе», красный «переплата». Решение за полсекунды.
4. 💸 **«Что в кармане» live** — крупно: вложено / в товаре / свободно / навар за месяц. Без занудных отчётов.
5. 📝 **Объявление в один тап** — из лота генерит готовый текст для Авито/Телеги + цену. Скопировал, вставил, продал.
6. 🔍 **Скан IMEI** — навёл камеру → статус: чистый / в розыске / залочен iCloud. Защита от мусора.
7. 📊 **Что брать** — тепловая карта: какие модели приносят больше и продаются быстрее. Бери то, что несёт деньги.
8. ⏳ **Радар висяков** — товар лежит N дней → СРМ сама толкает: «скинь 500₽ — улетит». Деньги не должны спать.
9. 🤖 **Телеграм-бот как фронт** — кинул фото телефона в бота → лот создан. СРМ всегда в кармане.
10. 🏆 **Серия / рекорд** — лёгкая геймификация: серия удачных сделок, личный рекорд маржи. Кайф от процесса.
11. 🔁 **Перекуп-нетворк** — отметил «ищу iPhone 13» → если у кого из своих есть, мэтчит. (на вырост)
12. 🧾 **Чек-сделка** — закрыл продажу → красивый чек покупателю в Телегу/PDF за секунду.

## Готовые промпты (копируй и вставляй ИИ-строителю)

> Каждый промпт самодостаточный. Можно давать по одному. Держи вайб из шапки.

### P0 · Каркас и дух
```
Сделай лёгкую СРМ для перекупа б/у телефонов. Не корпоративная — для простого парня, который ценит скорость.
Стиль: тёмная тема, крупные карточки, свайпы, живой язык (купил/продал/в кармане/висяк/навар), эмодзи к месту.
Главный экран: сверху крупно «навар сегодня» и «денег в товаре», ниже лента лотов карточками.
Любое действие — максимум 2 тапа или голос. Никаких длинных форм. Мобайл-первый.
Стек подстрой под существующий (Flask + SQLite + один index.html на ванильном JS), но логику опиши отдельно от вёрстки.
```

### P1 · Молниеносный приём лота (фото → ИИ → модель/цена)
```
Сделай экран «Новый лот» на скорость. Парень фоткает телефон — ИИ по фото определяет модель, память, цвет
и примерную рыночную цену, и подставляет это в карточку. Парню остаётся вбить ОДНУ цифру — за сколько берёт.
Сразу показывай маржу к рыночной цене крупно и «светофор» (зелёный/жёлтый/красный — выгодна ли покупка).
Сохранение лота — один тап. Если фото нет — поля заполняются голосом или вручную, но это запасной путь.
```

### P2 · Голосовой ввод сделки
```
Добавь голосовой ввод. Парень говорит свободным текстом: «взял айфон 12 64 синий за 18, продам за 25».
ИИ разбирает это в структуру: модель, память, цвет, цена покупки, цель продажи — и создаёт лот с посчитанной маржой.
Показать распознанное на подтверждение (можно поправить тапом), затем сохранить. Ошибся в распознавании — правит голосом же.
```

### P3 · «Что в кармане» — живой капитал
```
Сделай виджет-сводку капитала, всегда на главном экране, крупными цифрами:
вложено всего · сейчас в товаре (по закупке) · свободные деньги · навар за месяц (и за сегодня).
Без таблиц и отчётов — это пульс бизнеса, понятный за 1 секунду. Обновляется сам при каждой сделке.
```

### P4 · Генератор объявления (Авито/Телега)
```
Из карточки лота генери готовое объявление одним тапом: цепляющий заголовок, описание (модель, память, цвет,
состояние, что в комплекте), и цена продажи. Стиль — живой, как пишут перекупы, не сухой.
Кнопки: «Скопировать для Авито», «Скопировать для Телеги». Текст адаптируй под площадку (Авито подробнее, Телега короче).
```

### P5 · Проверка IMEI
```
Добавь проверку IMEI: ввод вручную или сканом камерой/QR. Показывай статус простым языком и иконкой:
чистый ✅ / в розыске ⛔ / залочен iCloud 🔒 / нет данных. Если телефон грязный — предупреди ДО покупки, крупно.
Источник проверки сделай абстракцией (провайдер можно подменить), с заглушкой-моком, пока нет реального API.
```

### P6 · Радар цен рынка
```
Сделай «радар цены»: для модели лота показывай среднюю цену по рынку (РФ + регион) и вилку (от/до).
На основе этого считай потенциальный навар и подсказывай цену продажи. Источник цен — абстракция с возможностью
подменить (сначала справочник/мок, потом реальные данные). Никогда не выдавай мок за реальную цену — помечай источник.
```

### P7 · Радар висяков (товар залежался)
```
Добавь логику «висяков»: если лот не продан N дней (порог настраивается), подсвечивай карточку и предлагай действие:
«скинь X₽ — уйдёт быстрее». Покажи, сколько денег «спит» в висяках. Цель — не давать капиталу залёживаться.
Без давления и морали — короткий бодрый тон: «подвинь цену — освободи кэш 💸».
```

### P8 · Телеграм-бот как фронт
```
Сделай Телеграм-бота входной точкой СРМ. Кинул в бота фото телефона → бот прогоняет через ИИ-оценщик (P1)
и создаёт лот, отвечает карточкой с моделью/ценой/маржой. Команды короткие: /налик (сводка кармана),
/висяки (что залежалось), /продал <id> <цена>. Бот и веб-СРМ работают с одной базой.
```

### P9 · Сделка в 2 тапа
```
Закрытие продажи — максимально быстро. На карточке лота кнопка «Продал» → один экран: цена продажи (предзаполнена целью),
покупатель (необязательно, быстрый выбор/создание), тап «Готово». Маржа и «навар сегодня» пересчитываются мгновенно.
Покупателя можно вообще пропустить — скорость важнее данных.
```

### P10 · Сводка дня
```
Сделай «итог дня» одним экраном (и копией голосом/в Телегу): сколько купил, сколько продал, навар за день,
лучшая сделка, что в товаре осталось. Лёгкий, бодрый тон с эмодзи. Это не отчёт — это «как день прошёл».
```

### P11 · Что брать (аналитика на скорость)
```
Сделай простой экран «Что брать»: по истории сделок покажи, какие модели приносят больше навара и продаются быстрее
(топ по марже и по скорости оборота). Вывод — пара строк-советов: «бери iPhone 11 — навар стабильный, уходит за 3 дня».
Без графиков-простыней: только actionable-подсказки.
```

---

## Как пользоваться
- Берёшь нужный промпт → даёшь ИИ-строителю (или мне) → получаешь фичу.
- Хочешь всё сразу — дай P0, потом P1–P3 (это ядро: приём, голос, капитал). Остальное наращивай по вкусу.
- Каждую фичу делаем поэтапно и проверяем на скорость: если действие дольше 2 тапов — переделываем.

> Дальше можно поднять отдельным модулем рядом с ремонтной СРМ или как отдельную «бушку» — на твой выбор.
