## Статус: активная фаза (июнь 2026)
Идея показана живым продавцам радиорынка — **боль подтверждена**. Проект перешёл из «пробуем» в **полную активизацию**. Дух, аудитория, стратегия — в `CREDO.md`.

## Что это
Маркет б/у вещей + мини-CRM продавца. Базовый цикл: выставить → найти → связаться → продано.
ДНК, аудитория и правила — в корневом `CLAUDE.md`.

## Состояние (2026-06-13, v0.2.0)
- React+TS+Vite PWA. Три экрана (Склад / Создать / Профиль), плавающий таб-бар.
- Перенос с площадок: вставка из буфера + парсер (заголовок, цена, контакт, категория, состояние, грейд, город, батарея, комплект).
- Экспорт: готовый текст для Telegram / Avito / ЛС.
- Хранение локальное (localStorage), квота-безопасное. SW v3 network-first (свежая версия сразу после деплоя), офлайн через кэш.
- Деплой: push в `main` → GitHub Actions → Pages.
- **Прод:** https://defancientmus-gif.github.io/bushka/
- **Репо:** github.com/defancientmus-gif/bushka

## Грани продукта (целевой образ)
- **Покупатель** — маркет: лента лотов, поиск, запрос продавцу, избранное. Вход без обязательств (снимает страх).
- **Продавец/перекуп** — CRM: склад, статусы, сделки, деньги (доход/расход/маржа), SMM-планер.
- **Доверие** — честный рейтинг за дела + задания. Без отзывов.

## Ограничение сейчас
Всё локально, один пользователь на устройстве. Настоящий маркет между людьми, два разных ЛК с идентичностью, честный рейтинг и задания — требуют общего бэкенда (Supabase). Это и есть ближайшая развилка — см. `NEXT.md`.
