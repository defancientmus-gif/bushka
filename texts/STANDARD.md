# Стандарт карточки БУ.шки (черновик из исследования рынка)

> Цель: задать единый формат, который превращает барахолку в «полку магазина».
> Источник: deep-research по мировым лидерам (Back Market, Swappa, CeX, NSYS, WholeCell, PhoneX, PriceCharting) + рынок РФ.
> **Статус достоверности:** факты собраны с первичных источников; машинная перепроверка прервана лимитом сессии — перепроверить после сброса. Описательные факты (как устроены грейды) — высокое доверие.

## Что делает витрину «полкой», а не барахолкой (паттерн индустрии)
Сошлось у всех лидеров — это и есть рецепт стандарта:

1. **Порог листинга (no junk).** Swappa не пускает треснутое стекло, битые кнопки — это держит каталог чистым. Наш разворот под ДНК «не говорим НЕТ»: не запрещаем, а **честно помечаем** дефект — но дефект нельзя спрятать.
2. **Грейд = только косметика, фиксированная лестница.** Back Market (Fair/Good/Excellent/Premium), Swappa (New/Mint/Good/Fair), CeX (A/B/C/F), NSYS (A/B/C/D) — 4 ступени, не свободный текст. Критерии **проверяемые**: у Back Market — «царапины не видно с 20 дюймов = Good, с 8 = Excellent». Субъективное «состояние» становится повторяемым.
3. **«Работает» отдельно от «выглядит».** У Back Market любой грейд = 100% функционален, батарея ≥80% (≥90% genuine для Premium). Swappa: всё с завода должно работать на ЛЮБОМ грейде. Грейд варьирует только косметику, не функцию.
4. **Комплект/коробка — отдельное поле** (CeX: A = с коробкой и всеми аксессуарами).
5. **Справочная цена по модели+грейду.** PriceCharting: одна каноническая запись, у каждого грейда — своя референс-цена. Это и есть анти-демпинг-сигнал.

## СТАНДАРТ БУ.шки (под нашу аудиторию — простой, не запрещающий, честный)
Единая карточка = фото + грейд + «работает» + комплект + цена. Конкретно:

- **Грейд A / B / C / D / Repair** (у нас уже есть) + человеческие критерии: A — как новый; B — лёгкие следы (не видно с вытянутой руки); C — заметные следы; D — сильный износ; Repair — на запчасти/под восстановление.
- **Батарея, %** — обязательно для смартфонов/ноутов (есть поле — сделать заметным).
- **Чек-лист «работает»** (новое, простое): экран · тач · камера · звук/микрофон · кнопки · разъёмы · Face/Touch ID · держит зарядку. Галочки, не текст. Это decoupling «работает ⟂ выглядит».
- **Дефекты — честно** (есть поле). Нельзя выставить «идеал», если отметил трещину.
- **Комплект / коробка** (есть поле).
- **Фото-стандарт:** обязательные ракурсы — перёд, зад, экран включён, дефект крупно. Подсказки-рамки при съёмке → единый вид витрины.
- **Цена + справочная вилка** (с двором): «рынок по этой модели и грейду — 14–16к».

## Инструменты: «находить, а не гоняться» + анти-демпинг
- **Справочная цена/вилка** по модели+грейду (наша БД сделок → референс). Демпинг становится виден, мелкого не вынуждают падать в пол. (PriceCharting-модель.)
- **Учёт по серийнику/IMEI**, не по количеству (WholeCell, PhoneX) — основа доверия и истории устройства.
- **Алерты «ищу X»** для перекупов: подписался на модель+грейд+цену → приходит, когда появилось. Это и есть «не гоняться».
- **Кросспостинг** одной карточки на площадки (WholeCell/Vendoo).
- **AI-грейд по фото** — реально и точно: NSYS Autograding ставит грейд по 6 фото за ~30с (заявлено 98.4%; ручная оценка субъективна — 30% техников меняют грейд при повторной). Подтверждает наш курс «сфоткал → продукт оценил».

## Анти-демпинг и анти-монополия (по слову Жени)
- **Освещаем справедливую цену**, а не навязываем: видна вилка — видно, кто рушит рынок.
- **Ранжируем по доверию и точности описания, а не по самой низкой цене** — это защищает честного мелкого продавца от гонки в пол.
- Мы **на стороне мелкого**: инструмент делает его профи, а не кормит монополиста.
