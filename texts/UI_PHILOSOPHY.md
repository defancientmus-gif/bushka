# UI_PHILOSOPHY — визуальные законы БУ.шки

Ориентир — нативный iOS: **Things 3, Bear, Fantastical.** Стекло, керамика, воздух, типографика.
Анти-ориентир — **Material Design**: никаких ripple, elevation, FAB, цветных полосок «для красоты».

## Законы
- **Материал:** матовое стекло `oklch(1 0 0 / .38)` + `backdrop-filter: blur(12px)`. Цвета только `oklch()`.
- **Перо, не пружина:** `cubic-bezier(.22,1,.36,1)`, .28–.32s, БЕЗ overshoot (отскок = дёрганье). Стаггер списков .04s.
- **Производительность — железно:**
  - в keyframes только `transform`/`opacity` (box-shadow/filter/blur в keyframes = горячий телефон);
  - НИКОГДА backdrop-filter на движущемся элементе;
  - blur ≤ 12px (один слой до 20px макс);
  - под открытым оверлеем фоновые infinite-анимации — на паузу (`animation-play-state: paused`);
  - `will-change` не оставлять на элементах с backdrop-filter.
- **Декор без задачи запрещён:** никаких `::before` «для акцента», градиентных рамок, цветных чёрточек.
- **Тёмная тема — полноправный гражданин:** каждый светлый хардкод сразу получает `html.dark`.
- **Структура:** 3 кнопки по центру — минимум шума. Не трогать без причины (слово Жени).

## Аудит текущего кода (v0.2.0) — где я отступил, долг к погашению
Глазу сейчас красиво и плавно (Женя: «идеально»), но под капотом есть отступления от законов. Гасить мягко — глаз не должен заметить ухудшения.

1. **Градиентная полоска `.import-hero::before`** — декор для красоты. → убрать.
2. **Палитра в hex/rgba, не `oklch()`** — перевести все токены на oklch.
3. **Градиентные кнопки + бесконечный `sheen` (движущийся блик)** — декор без задачи, лишнее движение, не паузится под оверлеем. → акцент одним oklch-цветом/стеклом, sheen убрать.
4. **`.flow-lines`: blur(7px) на контейнере с infinite transform-анимацией внутри** — движущийся blur = перерисовка = «телефон греется». → либо статичный фон без анимации под blur, либо очень дешёвая версия + пауза под оверлеем.
5. **flow-lines infinite не на паузе под открытым sheet** — добавить паузу.
6. **Длительности местами .34–.5s и кривые не «перо»** — привести к .28–.32s + `cubic-bezier(.22,1,.36,1)`.
7. **Нет тёмной темы** — ввести `html.dark` (прозрачное тёмное стекло, не серые плитки).

Хорошо уже: backdrop-filter только на статичных (tabbar), `will-change` не используется, `prefers-reduced-motion` уважается, статусы/иконки тонкой линией.
